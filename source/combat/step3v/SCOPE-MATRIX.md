| Family or case | Current NVO role | Evidence | Damage authority | Next requirement |
|---|---|---|---|---|
| Nine selectable bullet profiles | Exact admission, bounded flight ownership, integration, observation, cleanup and fallback | Live + offline | No | Read-only Step 4 shadow context, then Gate C |
| Two pilot-only profiles | Manual diagnostic support | Offline/configuration | No | Explicit activation decision and live coverage |
| Hunting-rifle AP and HP | Separate selectable flight identities | Configuration + existing flight evidence | No penetration or tissue distinction | Ammunition construction and armour interaction profiles |
| Unprofiled vanilla bullets | Existing engine/mod path | Design fallback | Engine/mod only | Explicit weapon/ammunition mapping |
| Modded or unknown bullets | Existing engine/mod path | Design fallback | Engine/mod only | Compatibility profile; reject ambiguous classification |
| Shotgun pellets | Outside accepted flight authority | Earlier observation only | Engine/mod only | Per-pellet admission, attribution, capacity and exact-once tests |
| Laser | Outside accepted Step 3 scope | No active family adapter | Engine/mod only | Beam/contact semantics and energy/armour profile |
| Plasma | Outside accepted Step 3 scope | No active family adapter | Engine/mod only | Projectile/thermal semantics and energy/armour profile |
| Flame | Outside accepted Step 3 scope | No active family adapter | Engine/mod only | Stream/contact/continuing heat attribution |
| Explosive projectile | Outside accepted Step 3 scope | No active family adapter | Engine/mod only | Separate travel impact from explosion and fragments |
| Grenade or thrown explosive | Outside accepted Step 3 scope | No active family adapter | Engine/mod only | Thrower attribution, fuse, impact and explosion rules |
| Throwing spear/knife | Outside accepted Step 3 scope | No active family adapter | Engine/mod only | Thrown-body flight, recovery and piercing context |
| Melee/unarmed | No projectile-flight role | No active family adapter | Engine/mod only | Cutting, piercing and blunt contact adapter |
| Actor/reference contact | Identity and correlation preserved in accepted capture | Live | No | Region policy and application boundary |
| World/reference contact | World classification and terrain clamp accepted | Live | No | Exact contact interval only if damage needs it |
| VATS | Observed through diagnostics | Live but incomplete | No | Aim/result/region/critical/scaling contract |
| Pre-movement or immediate contact | Unavailable to current estimator | Manifest + audit | No | Dedicated safe observation path or explicit fallback |
| Armour and injury | Pure offline model only | Offline | No | Guarded read-only shadow adapter, then Gate C |

The fallback rule is uniform: if NVO cannot classify a case with explicit validated data, it leaves the full existing engine or mod behavior in control.
